## Release proposal — CTDirect v2.0.0 (stable)

**Version.** Last release `1.1.8-beta`; last version in General `1.0.12`. Since `1.0.12`: breaking changes, in `1.1.0-beta` (the discretization API follows the CTSolvers dispatch contract) and `1.1.1-beta` (1-D state, control and variable reach user functions as scalars). By `REL1` (X ≥ 1: the breaking component is X) and `REL2` (the triple must be above every one released, betas included), the version is **`2.0.0`**.
**Jump in General (`REL3`).** none.
**Resolves from General alone (`REL4`).** ✅.
**Versions applied.** ct-agents `v0.5.0`, ct-conventions `v0.13.0`, CTActions `a9f0450` (the release tool).

### What changes since `1.0.12`

- Breaking: the discretization API (`1.1.0-beta`) and the 1-D scalars (`1.1.1-beta`), with their `BREAKING.md` entries.
- Bug fix: with `:exa`, the dual of a path or boundary label throws instead of returning a wrong `0` (#672).
- Enhancement: the path and boundary duals are given to CTModels by label.
- Dependencies: CTModels 0.21.1, CTSolvers 0.7, CTParser 0.9.6, CTBase 0.30, ExaModels 0.12; the GPU bounds keep the newest major. With CTSolvers 0.7 the sign of the costate and duals of a maximisation problem changes (near-breaking, `BREAKING.md`).
- Not in `[Unreleased]` yet, added by the release PR: the GPU bounds (#625) and `import` → `using` (#617), shipped by `1.1.7-beta`.
- Open PRs, not in this release: #661 to #669 (CompatHelper), #646 (retry moonlander).
